# Frames vectors

Normative test vectors for [spec/frames-and-units.md](../../spec/frames-and-units.md).
Each file states its `rule`, a `tolerance`, and `cases` with inputs and expected outputs.
Matrices are 16 (or 9) floats row by row; quaternions `[x, y, z, w]`.

| File | Rule (§) |
|---|---|
| `matrix_layout.json` | JSON matrices are row-major; column-major memory is transposed (§3) |
| `quat_vs_matrix.json` | Quaternion ⇄ matrix, Hamilton convention, `w ≥ 0` representative (§3) |
| `arkit_cv.json` | OpenCV ⇄ ARKit camera via `F = diag(1,-1,-1,1)` (§3) |
| `arkit_face_to_cv.json` | ARKit face anchor to stored `T_cvcam_from_face`, nose-tip sign check (§3) |
| `euler_signs.json` | Head yaw/pitch/roll signs and gimbal lock, upright stream (§3) |
| `upright_euler.json` | Display-upright angles for every EXIF orientation, and the inverse (§3) |
| `vision_pose.json` | Vision face angles to file angles; orientation table (§3) |
| `bins.json` | Yaw/pitch bin ids, condition labels, stills-bank up/down override, bin keys (§3) |
| `backproject.json` | Pixel centres, back-projection, depth holes, intrinsics scaling (§4) |
| `gnm_template.json` | `T_headcanon_from_gnmtemplate` for GNM Head v3 as shipped, with check points (§2) |

All files except `gnm_template.json` are generated by `tools/gen_frames_vectors.py` by
forward construction (compose rotations from known angles, apply formulas, or hand-written
cases), never by running a decomposition under test. `vision_pose.json` cases carry
`verified_on_device: false`: they follow Apple's documented conventions and have not been
confirmed on a device.
